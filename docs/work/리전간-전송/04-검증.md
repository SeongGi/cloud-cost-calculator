# 04. 검증: 리전 간·인터넷 데이터 전송 비용

## 진행 기록
- 설계: 독립 검토 3회 진행. 1차 12건, 2차 3건, 3차 1건을 지적받았다. 3차도 "수정 필요"였으며, 남은 1건(병합 전 기본값 채우기)은 검토자 제안대로 고치고 사용자에게 보고했다(02-설계.md 11절).
- 코드: 독립 리뷰 2개(엔진·이어지는 질문 / 빌더·가격표·갱신)를 동시에 돌렸고, 수정은 3회 진행했다. 1회차 지적 9건(높음 2), 2회차 새 회귀 3건(중간 2)을 고쳤다. 3회차는 마지막 회차라 재검토 없이 회귀 테스트와 변이 검증으로 확인했다.

## 가격표
- 새 키만 빌드해 번들에 병합했다. 빌더 경고 0건, 항목 수 AWS 50, Azure 35, GCP 44. 기존 항목 diff 0(리뷰 B가 HEAD와 비교).
- 단가 대조(공식 API, 2026-10-25): AWS 서울→도쿄 0.08, 서울 인터넷 0.126, 도쿄→서울 0.09, 버지니아→서울 0.02 / Azure 한국 중부 인터넷 0.12, 미국 동부→한국 중부 0.05, 한국 중부→미국 동부 0.08, 한국 중부→일본 동부 0.08 / GCP 리전 간 0.08, 인터넷(한국 대상) 0.19.
- 알려진 표기 차이: AWS 번들의 `source`는 `aws_price_list_query_api`이고 새 항목은 bulk 파일로 만들었다. 두 경로 모두 같은 AWS Price List 데이터이므로 표기는 바꾸지 않았다.
- 번들 `as_of`는 그대로다. 새 단가의 게시일은 각 항목(AWS `published`, Azure `effective_start`, GCP `effective_time`)에 남아 있다.
