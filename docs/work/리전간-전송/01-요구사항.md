# 01. 요구사항: 리전 간·인터넷 데이터 전송 비용

## 목표
- 사용자가 "서울에서 도쿄로 매달 1TB 복제", "인터넷으로 500GB 나감"처럼 말하면, 계산기가 데이터 전송 요금을 별도 줄로 계산한다.
- AWS·Azure·GCP 세 클라우드 모두, 가격표가 지원하는 세 리전(서울·도쿄·미국) 사이의 송신과 인터넷 송신을 다룬다.

## 하지 않을 것
- 구간별(tiered) 누진 계산: 첫 유료 구간 단가 하나로 계산한다. 기존 규칙(단가 × 수량)을 바꾸지 않는다.
- 무료 구간(AWS 계정 단위 100GB, Azure 첫 100GB, GCP 첫 1GiB) 반영: 기존 정책대로 프리 티어는 뺀다.
- 들어오는 전송, 같은 리전 안 AZ 간 전송, CDN·Direct Connect·Interconnect·PrivateLink 전송.
- 세 리전 밖의 도착지(유럽, 싱가포르 등)와 대륙별 인터넷 단가 선택.
- 기존 가격표 항목의 재생성: 새 항목만 공식 API로 빌드해 기존 가격표에 더한다.

## 성공 기준
1. 클라우드마다 `data_transfer` 서비스가 생기고, 대안 선택 상자에서 도착지(다른 두 리전, 인터넷)를 고를 수 있다.
2. 모델이 spec에 도착지를 한국어("도쿄", "미국")나 영어("tokyo"), 리전 코드로 넣어도 그 도착지 단가가 선택된다. spec이 비면 사용자 문장에서 도착지가 하나로 정해질 때만 그것을 쓴다.
3. 손계산 일치: 클라우드마다 1개 이상(예: AWS 서울→도쿄 1000GB = 0.08 × 1000 = $80.00).
4. 단가는 공식 가격 API 값과 같다(AWS Price List bulk `AWSDataTransfer`, Azure Retail Prices `Bandwidth`, GCP Cloud Billing Catalog `Compute Engine`).
5. 결과 카드에 "첫 유료 구간 단가, 무료·할인 구간과 들어오는 전송 제외"라는 안내가 나온다.
6. 기존 테스트(파이썬·vitest)가 모두 통과한다.

## 운영 위험
- 일일 가격 갱신(`refresh.py`)이 새 항목도 빌드하므로, 필터가 특정 리전에서 0개나 2개를 찾으면 그 항목이 빠진다. 빌더가 이미 경고 후 이전 값을 이어 쓰므로 계산 자체는 멈추지 않는다.
- GCP 빌드에는 `gcloud auth print-access-token` 토큰이 필요하다.

## 확인한 사실 (2026-10-25, 공식 API 직접 조회)
- AWS: `AWSDataTransfer` 리전 파일에 `fromRegionCode`·`toRegionCode`·`transferType` 속성이 있다. 서울→도쿄·버지니아 $0.08, 도쿄→서울·버지니아 $0.09, 버지니아→서울·도쿄 $0.02. 인터넷(`AWS Outbound`, `toLocation=External`) 첫 구간(0~10TB) 서울 $0.126, 도쿄 $0.114, 버지니아 $0.09.
- Azure: 리전 간 전송은 대륙 미터(`Bandwidth Inter-Region`)로 정한다. 아시아 안 $0.08, 아시아→다른 대륙 $0.08, 북미→다른 대륙 $0.05(첫 5GB 무료). 출발 리전별 미터 `Standard Inter-Region Data Transfer`(한국 중부 $0.08, 미국 동부 $0.02)는 대륙 구분이 없어 쓰지 않는다. 인터넷은 `Rtn Preference: MGN`의 `Standard Data Transfer Out`이며 0~100GB가 무료, 100GB부터 한국 중부 $0.12, 미국 동부 $0.087.
- GCP: `Network Inter Region Data Transfer Out from {Seoul|Japan|Americas} to {Seoul|Japan|Americas}`가 모두 $0.08이다(미국→도쿄는 첫 1GiB 무료 후 $0.08). 인터넷은 도착 대륙마다 SKU가 따로 있다. 한국 사용자 대상(`to South Korea`)은 세 리전 모두 첫 유료 구간 $0.19이다.

## 열린 질문
- GCP 인터넷 도착지를 한국 하나로 고정하는 결정은 이 서비스의 사용자층(한국)에 맞춘 것이다. 다른 대륙 선택은 후속 작업으로 남긴다.
