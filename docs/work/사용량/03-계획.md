# 03. 계획: 커밋 단위

| # | 커밋 | 검증 명령 |
|---|---|---|
| 1 | agent: `src/usage.py`(sqlite·해시·정리·summary), `src/usage_middleware.py`, `RunLimiter` busy 기록, `ResponseGuard` 실패·빈 답변 기록, `pricing.engine.RESULT_STATES`, 관리 API `POST /admin/usage/question`·`GET /admin/usage`, `tests/conftest.py`, `tests/test_usage.py` | `cd apps/agent && uv run pytest` |
| 2 | app: `src/lib/usage.ts`(threadId 추출·limited 중복 제거·`after()` 기록), copilotkit route, 관리 프록시 `usage`·`days`, 관리 화면 사용량 카드와 CSS, vitest; 문서 `docs/work/사용량/*` | `pnpm --filter @repo/app test`, `pnpm --filter @repo/app build`, 전체 pytest |

두 커밋은 서로 다른 앱만 고치고, 1번만 있어도 테스트가 모두 통과한다. 그래서 1번과 2번을 동시에 구현한다. app은 설계 2절의 summary JSON 모양만 따른다.
